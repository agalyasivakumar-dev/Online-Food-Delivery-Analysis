Online Food Delivery Analysis

**Project Overview**
This project analyzes 100,000 online food delivery orders to identify trends in customer behavior, revenue, profitability, delivery performance, and order cancellations.

The project covers data cleaning, exploratory data analysis (EDA), SQL analysis, visualization, and an interactive Streamlit dashboard.

**Objectives**
Analyze customer and order patterns
Identify revenue and profit trends
Study the impact of discounts
Evaluate delivery performance
Analyze cancellation patterns
Identify high-performing cities and cuisines
Build an interactive dashboard for business insights

**Tools & Technologies**
Python – Pandas, NumPy
SQL / MySQL – Data storage and analysis
Plotly – Data visualization
Streamlit – Interactive dashboard
VS Code

**Project Workflow**
Data → Cleaning → EDA → SQL Analysis → Visualization → Dashboard → Insights

**Data Cleaning**
Handled missing values
Corrected data types
Standardized categorical values
Handled invalid and inconsistent values
Created derived columns for analysis

**Analysis**

**Key areas analyzed:**

Customer & Order Analysis
Revenue & Profit Analysis

**Key Outcome**
The project transforms raw food delivery data into actionable business insights related to customers, revenue, profitability, delivery performance, and cancellations through SQL analysis and an interactive dashboard.
